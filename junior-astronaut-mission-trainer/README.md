# Junior Astronaut Mission Trainer

An interactive space mission simulation developed for
NASA Space Apps Challenge 2026.

## Team

- Frontend / UI-UX
- Game Logic / Simulation
- NASA Research & Content
- AI / Backend & Integration

## Project

Players manage a Moon/Mars outpost by balancing resources,
responding to mission events, and making critical decisions.

## Technologies

- React
- Vite
- JavaScript
- AI / APIs
- NASA Open Data
